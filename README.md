# ⚽ Football AI Analyzer

Herramienta personal de análisis estadístico de fútbol.

## Objetivo

Construir un sistema reproducible que analice partidos, estime probabilidades y mida su rendimiento histórico. Las predicciones son estimaciones estadísticas y no garantizan resultados.

## Stack gratuito inicial

- Python + pandas + NumPy + SciPy + scikit-learn
- HTML/CSS/JavaScript para el dashboard
- Supabase Free como base de datos cuando se conecte
- football-data.org Free como fuente primaria inicial
- GitHub Actions para automatización

## Modelos

1. Poisson
2. ELO
3. Monte Carlo
4. Ensemble
5. Backtesting y calibración

## Seguridad

Nunca guardar API keys, contraseñas o credenciales en el repositorio. Usar GitHub Secrets y variables de entorno.
